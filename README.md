# SupplyOS

AI-Powered Manufacturing & Supply Chain Intelligence Platform.

## Overview

SupplyOS helps businesses discover and connect with:

- Suppliers
- Manufacturers
- Packaging Partners
- Warehouses
- Quality Testing Labs
- Logistics Providers
- Business Consultants

The platform uses an AI-driven recommendation engine to match business requirements with suitable partners based on industry, certifications, MOQ, production capacity, location, lead time, and specialization.

## Features

- AI-powered supplier recommendations
- Intelligent RFQ generation
- Manufacturing project workspace
- Enterprise marketplace
- Industry-specific partner directories
- Procurement planning
- Requirement discovery workflow
- Business consultant recommendations

## Installation

### Frontend

```bash
cd FRONTEND
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
